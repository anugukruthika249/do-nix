# 🩸 Donix — Real-Time Blood Donation Platform

## About

Donix is a real-time blood donation platform built to address a critical problem — delays in finding blood donors during emergencies. The goal of this project is to create a system where users can quickly raise requests and connect with potential donors without unnecessary friction.

---

## Key Features

* Real-time blood request creation and tracking
* Instant data synchronization using cloud database
* SOS alert system for emergency situations
* Clean and user-friendly interface
* Efficient handling of donor and request data

---

## Tech Stack

* Frontend: React.js, HTML, CSS, JavaScript
* Backend: Firebase
* Database: Firestore
* APIs: Twilio (for SOS alerts)
* Tools: Git, GitHub, VS Code

---

## How It Works

Users can create a blood request, which is instantly updated in the system and visible to others. The platform ensures that requests are tracked in real time, allowing faster responses. In emergency situations, the SOS feature helps trigger alerts to improve reach and response time.

---

## Impact

This project focuses on solving a real-world problem where time is critical. By reducing the delay in communication between donors and recipients, Donix aims to improve response efficiency and support emergency healthcare situations.
